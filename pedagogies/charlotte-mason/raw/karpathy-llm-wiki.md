## Independent description

The “LLM Wiki” gist proposes a personal knowledge system in which an agent
maintains a durable, cross-linked set of Markdown notes. New sources are read
and integrated into existing summaries, entity pages, and concept pages when
they arrive. Questions are then answered from that maintained synthesis, and
useful answers can become new wiki pages. A schema file defines the directory
structure and the workflows for ingestion, querying, and maintenance. The
approach is offered as an alternative to reconstructing the same relationships
from retrieved source fragments for every question.
