# Support

Charlotte is a small open-source project maintained from a working family system. There is no guaranteed response time or compatibility commitment for every operating system, agent harness, provider, curriculum, spreadsheet layout, or third-party service.

## Bugs

Before opening an issue:

1. remove student names, family records, curriculum text, credentials, tokens, private hosts, and message attachments;
2. reduce the problem to the smallest reproducible example using fictional data;
3. include the Charlotte commit, operating system, Python version, active runtime or coding agent, command or skill used, expected result, and sanitized error output; and
4. check whether the problem belongs to Charlotte or to a separately maintained dependency or service.

Focused bug reports and fixes are welcome through GitHub issues and pull requests once the repository is public.

## Questions and community help

Use GitHub discussions if they are enabled. Otherwise, use a GitHub issue for a concrete documentation gap or reproducible question. General homeschooling advice, curriculum selection, provider account support, and debugging private household infrastructure are outside the project's support scope.

## Security and privacy

Do not publish a suspected vulnerability, secret, private record, or identifying family information in an issue. Follow [SECURITY.md](SECURITY.md).

## Paid support

No paid Charlotte support program is currently offered or promised. Any future consulting or commercial support will be described separately and will not reduce the rights granted by the Apache-2.0 license.
